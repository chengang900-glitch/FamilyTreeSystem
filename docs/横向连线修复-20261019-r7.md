# 横向树形连线修复（r7 历史记录）

本记录保留 r7 当时的显示规则；当前 r9 已恢复横向夫妻框，子女从配偶右侧接出，见[当前发布记录](发布-20261019-r8-r9.md)。

用户反馈：纵向显示正确，横向夫妻线和亲子线混乱。

## 原因与修复

横向树形将主成员居中在整组后代的高度上，配偶却放在该组顶部，造成很长的夫妻折线。多个子女同列排列时，连线仍全部进入子女顶部，公共干线不得不逐个折回。

本次只修改 `web/src/pedigree/layout.ts` 和 `scripts/test_layout.mjs`：

- 横向树形的主成员与第一位配偶对齐，夫妻线不再随后代数量上下错开。
- 多子女继续从实际登记双亲中的配偶底部接出，共用左侧竖干线，从各子女左侧进入；单个子女仍向下连接顶部。
- 保留多段婚姻、女性主成员/女婿和单亲语义，不补造亲子资料。
