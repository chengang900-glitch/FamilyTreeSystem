# 世系树实施计划

用户已确认修复方案并授权代码修改及服务器部署。本会话直接执行，不提交此前已有的工作区修改。

目标：真实表达夫妻、共同父母、不同生养类型和多段婚姻；家庭成员相邻、分层正确，横纵切换和导出一致。附带收窄成员列表所属分支列。

1. `server/blueprint/pedigree_bp.py` 返回 `marriages`（ID、双方、成员 A 次序）、`parentchild`（ID、父母、子女、类型），保持已有节点响应、谱内权限和隐私规则；新增隔离接口测试，核对未登录/跨谱拒绝及关系类型保真。
2. `web/src/pedigree/layout.ts` 增加 `buildScene(kind,nodes,root,orientation,directOnly,relations)`，返回节点、类型化折线路径、家庭组、数据提示和完整边界。根据亲子和配偶关系建立家庭块，计算层级、子树空间、方向与避障；同一人员仅放置一次。`layoutOf` 保留原调用兼容性。用 `scripts/test_layout.mjs` 覆盖双亲、再婚、单亲、收养、多根、方向和穿卡检测。
3. `web/src/pages/Pedigree.tsx` 使用同一 scene 绘制和导出，夫妻/亲子不同线型、标签与图例；统一像素坐标缩放、居中、100% 入口与关系高亮；显示可见/总人数。`Persons.tsx` 分支列固定合理宽度、省略长文并提供完整提示。
4. 类型检查、布局检查、相关后端回归通过后，启动独立临时库实际浏览器检查五种布局、横纵切换、直系筛选、关系高亮、缩放及三种图片导出；检查导出图形和无截断。
5. 制作 r4 发布包，在原服务器构建 amd64 新镜像。只停止家谱服务，备份全数据卷、SQLite 和 Compose；在无网络临时容器内核对数据，再切换健康服务，核对其他容器和 Caddy 未变、公网资源更新。保留旧镜像及快照。

验收命令：`node scripts/test_layout.mjs`、`python scripts/test_pedigree.py`、`python scripts/test_profile.py`、`python scripts/test_reference.py`、`npm --prefix web run build`。测试只使用隔离临时库；公网不写测试资料。
