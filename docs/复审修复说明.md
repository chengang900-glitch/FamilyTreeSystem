# 复审修复说明（2026-10-18）

> 后续产品功能补齐见 [产品功能补齐说明](产品功能补齐说明.md)；当前后端测试总计 212 项。

本说明对应第二次代码审查发现的问题。除特别说明外，所有改动均保持原有接口路径和响应结构兼容。

## 一、安全修复

### 1. 资源路径穿越（P0）

- 新增 `server/service/filepath.py`：所有上传目录路径统一经过 `safe_upload_path()` 校验，拒绝绝对路径、`..` 和解析后逃逸上传根目录的路径。
- 下载、删除、导出、上传目录创建全部改用安全路径。
- 导入 JSON 不再信任源 `storage_path`：没有 ZIP 原件时写入空路径，避免把服务器任意文件挂进资源库。
- 启动时清理历史库中逃逸上传目录的 `storage_path`（只清空字段，不删除文件）。
- 资源上传数据库写入失败时会删除刚保存的文件，避免孤儿文件。

**行为变化**：只导出 JSON、不带资源原件的导入包，导入后资源记录保留但“原件缺失”；需要原件时请导出带 `resources/` 的 ZIP。

### 2. 受信代理 XFF

`client_ip()` 改为从右往左取第一个非受信代理地址，并校验 IP 格式。Nginx 仍使用 `$proxy_add_x_forwarded_for` 也不会再被客户端伪造的首段欺骗。

### 3. 密钥与认证

- `data/secret.key` 创建/读取时尽力设置为 `0600`。
- 新增用户默认 `must_change_pwd=1`；如自动化脚本需要用户立即访问接口，请显式传 `must_change_pwd: false`。
- 超级管理员不能停用自己，避免单超管把自己锁死。
- JSON 写接口统一要求根节点为对象；非法 JSON 返回 400，请求体超限返回 JSON 413。

### 4. 权限边界

- 家谱管理员不能再移除其他家谱管理员；移除管理员仅超管可做。
- 家谱管理员搜索可加入用户时：
  - 非超管只允许**精确匹配**账号或姓名；
  - 不返回手机号；
  - 超管仍可模糊搜索。
- 归档家谱对普通成员统一返回 403，超管仍可维护。

## 二、数据一致性修复

### 1. 删除家谱

删除顺序改为：

```
eventperson → resource_relation → marriage → parentchild
→ person → event → branch → resource → family_members → family
```

带婚姻、亲子关系的家谱现在可以正常删除，事务仍保证整体成功/回滚。

### 2. 导出/付印脱敏

JSON、CSV、GEDCOM、PDF、Word 全部应用 `privacy.mask_person()`，普通成员不能通过导出或打印绕过“在世者信息脱敏”。

### 3. 分支成员增量保存

- 后端 `PUT /api/families/<fid>/branches/<bid>` 新增 `add_ids` / `remove_ids` 增量语义；原 `person_ids` 全量语义保留兼容。
- 前端编辑分支改为提交增量集合。
- 家谱超过 500 人时，未加载成员的 `branch_id` 不再被静默清空。

### 4. GEDCOM 亲子关系

- 导出时不再把“配偶的子女”无条件挂到夫妻 FAM。
- 只有父母双方都与子女有亲子关系时才使用夫妻 FAM；单亲、再婚、多父母分别用单亲 FAM 表达。
- 导入单亲 FAM 只建立实际存在的一位父母关系，并去重。
- 导入结束后统一检查亲子环和分支层级环。

### 5. 资源关联与删除

- 删除婚姻/亲子时同步清理 `resource_relation`，启动时也清理历史悬空关系。
- 移除事件参与人、资源关联时增加父对象归属校验和审计。
- 覆盖导入成功后清理旧资源文件；失败回滚时保留原件。

## 三、婚姻关系维护

婚姻数据模型保持不变：**一条 `marriage` 记录就是一对配偶**；同一成员可以出现在多条记录中，因此三段及以上婚姻可以完整登记。

界面调整：

- “配偶一/配偶二”改为中性的“成员 A/成员 B”；
- 标题改为“婚姻管理（每行一段婚姻）”，弹窗改为“添加/编辑这一段婚姻”；
- 增加说明：每条记录只维护一对关系，同一成员可继续添加多条记录；
- 增加按成员姓名筛选；
- “婚姻次序”改为“本段次序”，用于同一成员多段婚姻排序。

后端仍用 `spouse1_id/spouse2_id` 存储一对配偶；`_assert_unique_marriage()` 仍阻止同一对成员重复登记。如需登记同一对配偶的复婚，请编辑原记录或先删除旧记录。

## 四、其他修复

- 付印页数预估会带上 `include_spouse/include_children`；`generations` 字符串自动转整数，`paper` 非字符串返回 400。
- 缺失的 `/assets/*` 返回真正 404，且错误响应不再被标记为一年 `immutable`。
- CSV 导出对 `= + - @` 开头的单元格加前缀，降低 Excel 公式注入风险。
- 导入限制 ZIP 文件数（10000）和解压后总体积（1 GiB）；导出 ZIP 使用 `SpooledTemporaryFile` 降低内存峰值。
- 移动端成员列表增加分页；移动端抽屉增加家谱切换。
- 资源关联选择器修复亲子关系显示为 `undefined & undefined` 的问题。
- 移除家谱“可见性=公开只读”的无效选项和标签（该功能未实现）。
- 多 worker 首次启动时 `system_settings` 使用 `INSERT OR IGNORE`，超管创建竞态不再导致 worker 启动失败。
